# Checklist posting & submit (S12) — berbantuan, BUKAN otomasi

Sumber aturan: pengalaman produksi dua campaign [D]. Login, klik OAuth ("Continue" otorisasi), dan CAPTCHA **hanya bisa dilakukan user sendiri**.

## Sebelum posting
☐ `brief_audit.md`: 0 FAIL, 0 PENDING; N/A punya alasan + izin
☐ `caption_tiktok.txt` memuat hashtag wajib, tag akun, CTA (cek `brief_audit` AUTO-hashtag/tag/cta)
☐ Narasi dari brief yang tidak diucapkan → ada di caption TikTok (bukan di video)
☐ File final = file yang sudah disetujui G-HUMAN (nama + durasi + ukuran dicatat)

## Posting (TikTok via browser, oleh user)
☐ Unggah `final.mp4`, tempel caption, atur privasi **Publik**
☐ **Verifikasi setelah publish:** TikTok kadang mengubah unggahan baru menjadi "Only me" saat peninjauan → cek di TikTok Studio dan perbaiki ke Publik [D]
☐ Catat waktu tayang (WIB) dan tautan di `production-log.md` (tanpa menyimpan kredensial)
☐ Bila ada kesalahan fatal: hapus dan unggah versi baru (preseden: versi tanpa VO dihapus) — jangan unggah ulang tanpa G-HUMAN

## Edit bio/profil (bila diminta brief)
Pengisian form secara programatik bisa gagal diam-diam; ketikan per karakter yang berhasil [D]. Verifikasi hasilnya di halaman profil.

## Submit ke konten.com
☐ Submit **≤24 jam** setelah posting [D]
☐ Wizard memilih video dari **picker akun terhubung** (bukan tempel URL) [D]
☐ Akun TikTok terhubung via OAuth; tombol otorisasi "Continue" **hanya user** yang bisa klik [D]
☐ Video wajib tayang **≥5 hari**; review dimulai setelah min views tercapai [D]
☐ Status awal biasanya "Pending" — catat; jangan mengklaim "disetujui" sebelum ada bukti

## Larangan
Tidak ada botting, tidak ada reupload utuh, tidak ada pelanggaran larangan SARA/AI di brief.
